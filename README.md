# 🌤 WeatherPro App

A modern and responsive weather web application that provides real-time weather updates, 5-day forecast, and location-based weather using the OpenWeather API.

---

## 🚀 Features

* 🌡 Real-time temperature data
* 📊 5-day weather forecast
* 📍 Location-based weather using GPS
* 🌅 Sunrise & Sunset timings
* 💨 Wind speed, humidity, and pressure
* 🎨 Dynamic background based on weather conditions
* 📱 Fully mobile-responsive design

---

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript
* OpenWeather API
